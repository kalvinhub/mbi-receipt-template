# Resit Penggunaan - Park@Perak

Web app to generate parking usage receipts (Resit Penggunaan) as PDF.

## 🌐 Live App
[Click here to open the app](#) ← replace with your Streamlit URL after deploy

## 📁 Files
| File | Purpose |
|------|---------|
| `app.py` | Streamlit web app |
| `generate_resit.py` | Standalone script (run locally) |
| `logo.jpg` | Park@Perak logo |
| `requirements.txt` | Python dependencies |

## 🚀 Deploy to Streamlit Cloud
1. Push this repo to GitHub
2. Go to https://streamlit.io/cloud
3. Sign in with GitHub
4. Click **New app** → select this repo → set **Main file** to `app.py`
5. Click **Deploy**

## 💻 Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
